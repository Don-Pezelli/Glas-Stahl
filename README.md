# Glas-Stahl

**…hauptsache kein Plastik.**

Eigenständige statische Website für Produkt-Reviews, Materialwissen und langlebige Alternativen.

## Lokal ansehen

`index.html` im Browser öffnen. Die Seite benötigt keinen Build-Schritt.

## Mit GitHub Pages veröffentlichen

1. Im GitHub-Repository unter **Settings → Pages** die Veröffentlichung über den Branch `main` und den Ordner `/ (root)` auswählen.
2. Speichern und warten, bis GitHub Pages die Website bereitgestellt hat.

Die Inhalte der Website liegen direkt im Repository-Root.
